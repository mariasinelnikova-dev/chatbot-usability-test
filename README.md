# Прототип умного чата поддержки

Кликабельный прототип сценария возврата в чате поддержки Aviasales. Экран как на iPhone: `390×844`.

## Открыть в браузере

https://mariasinelnikova-dev.github.io/chatbot-usability-test/

Локально:

```bash
node server.mjs
```

Затем открыть `http://localhost:4173`.
